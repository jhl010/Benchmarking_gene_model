## Installation

### Using Conda (Recommended)

```bash
# Clone the repository
git clone https://github.com/jhl010/Benchmarking_gene_model.git
cd Benchmarking_gene_model

# Create and activate conda environment
conda env create -f environment.yml
conda activate cheminfo
```

### Data availability

The ring-system frequency references for ZINC20 and ZINC22 drug-like molecules are provided under the `data` folder as `ZINC20_rings_ststem.csv` and `ZINC22_rings_system.csv`. The three reference datasets used as controls are included in the `FDA_approve_sm_molecules`, `ChEMBL_clinical_smmolecules` and `Crossdock_datasets` folders.

The Bemis-Murcko (BM) scaffold files extracted from ZINC20 and ZINC22 drug-like molecules are too large to store directly in this repository (`standardized_BM_scaffolds_ZINC20.smi`, about 478 MB, and `standardized_BM_scaffolds_ZINC22.smi`, about 56 GB). They can be downloaded from [Hugging Face](https://huggingface.co/datasets/yang2531/BM_scaffold_ZINC) and should be placed in the `data` folder before running the BM-scaffold coverage analyses.

## Structure of the repository

### Molecules generated by each algorithm

Generated molecules are saved in folders named after the respective models. Each model folder contains:

- `combined_SMILES_*_generated.txt` — the generated molecular set (the prefix follows each model folder).
- `Ring_systems.py` — applies MolVS standardization, the ChEMBL/ZINC20/ZINC22 ring-system frequency metrics, PAINS/Reymond/RO5 and other medicinal-chemistry filters, and writes `ring_systems_summary.csv`.

The seven locally deployed models are TargetDiff, DecompDiff, PocketFlow, GraphBP, Apo2Mol, DiffSBDD and AutoFragDiff. The PocketFlow `max_atom_num` sensitivity analysis is stored in `PocketFlow_max_atom_num_25`, `PocketFlow_max_atom_num_30`, `PocketFlow_max_atom_num_35`, `PocketFlow_max_atom_num_40` and `PocketFlow_max_atom_num_45`.

### Applying metrics to your own molecules

- For the ChEMBL ring-system frequency metric, see the `Ring_systems.py` file in each model folder, the original `useful_rdkit_utils` demo, and Dr. Walters’ ring-system blog posts.
- For BM-scaffold occurrence, use `BMScaffoldChecker.py` (ZINC20) and `BM_scaffold_checker_ZINC22.py` (ZINC22) after downloading the corresponding BM-scaffold reference files.
- `Filtering_functions.py` provides the Reymond filter, and `sascorer.py` together with `fpscores.pkl.gz` computes the synthetic accessibility (SA) score.
- `pocketflow_size_stratification.py` reproduces the heavy-atom-number-stratified structural-prior analysis.

- `pocketflow_max_atom_sensitivity.py` reproduces the PocketFlow `max_atom_num` sensitivity analysis across the 25, 30, 35, 40 and 45 folders.
- `BM_scaffolds_occurance.py` batch-runs ZINC20 and ZINC22 BM-scaffold coverage for all controls, model collections and PocketFlow sensitivity folders.
- `Picture_drawing.py` loads the repository-generated summary files, computes the nine molecular properties from the standardized SMILES collections, runs the KS / Cliff’s delta / bootstrap analyses, and writes the publication figures and statistical tables to `analysis_output/Picture_drawing`.

A reproducible order for the analyses is: run each `Ring_systems.py`, then `BM_scaffolds_occurance.py`, then `pocketflow_size_stratification.py` and `pocketflow_max_atom_sensitivity.py`, and finally `Picture_drawing.py`.
